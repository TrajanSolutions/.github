# Trajan Solutions

**Learn by building, measuring and documenting.**

We explore cloud infrastructure, defensive security, wireless systems and IoT. This GitHub space shares approachable learning paths, exercises and examples as they develop.

## Choose a learning path

| Path | What you'll learn | Start here |
| --- | --- | --- |
| NUBES and storage | How a file-storage service fits together; future Nextcloud deployment and recovery labs | [NUBES guides](https://github.com/TrajanSolutions/nubes-guides) |
| Defensive security | Connect threats to controls and evidence; future hardening exercises | [Security guides](https://github.com/TrajanSolutions/security-guides) |
| Wireless and IoT | Plan repeatable experiments across LoRa, LoRaWAN, Wi-Fi HaLow and Meshtastic | [IoT guides](https://github.com/TrajanSolutions/iot-guides) |

## What is available today?

Each path includes a beginner planning exercise, a learning roadmap and a template for future hands-on tutorials. Hardware-tested labs and runnable deployment tutorials are planned; each will identify its tested versions and limitations when published.

## Learn with us

Open an issue in the relevant guide repository to suggest a topic or ask a question. Corrections and clearly documented experiments are welcome through pull requests. Use synthetic data and remove credentials and private locations from anything you share.

Business operations and customer environments are maintained separately from these public learning materials.
